# SQL Interview Questions 
## Tables
- Customers(customer_id, first_name, last_name, age, country)
- Orders(order_id, item, amount, customer_id)
- Shippings(shipping_id, status, customer)

## Questions
1. Find customers who have placed more than one order.

``` Expected concepts: JOIN, GROUP BY, HAVING ```

2. Find the customer who has spent the highest total amount.

``` Expected concepts: SUM(), GROUP BY, ORDER BY, LIMIT ```

3. Find customers who have not placed any order.

``` Expected concepts: LEFT JOIN, NULL check ```

4. Find customers who placed orders but do not have shipping information.

``` Expected concepts: LEFT JOIN, multiple tables, missing relationship handling ```

5. Find the second highest order amount.

``` Expected concepts: subquery, MAX(), or ORDER BY with LIMIT/OFFSET ```

6. Find total revenue generated by each country.

``` Expected concepts: JOIN, SUM(), GROUP BY ```

7. Find customers whose total order amount is greater than the average total order amount of all customers.

``` Expected concepts: subquery, aggregation over aggregation ```

8. Display customer name, ordered item, amount, and shipping status for all customers, including customers with no orders.

``` Expected concepts: LEFT JOIN, multi-table joins ```

9. Find the most expensive order placed by each customer.

``` Expected concepts: correlated subquery or window function logic ```

10. Classify each order as High Value, Medium Value, or Low Value.
 
 Example condition:
```
amount >= 1000 → High Value
amount >= 500  → Medium Value
else           → Low Value
```
``` Expected concepts: CASE WHEN ```
